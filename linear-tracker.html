AIP-2710 Superagent run stops on large doc parsing (SOC 2) Medium
Assignee · Will Liu · Created Aug 31, 2026 · Production bug
Live incident with an active fix rollout — this Linear thread is syncing in real time with a Slack channel.
Details

Root cause: parsing a large SOC 2 document happens inline inside the agent's turn and takes ~5 minutes, but the whole turn has only a 10-minute budget — so the run gets killed mid-parse.

Benny Chen's proposed fix: make parsing an async background job with a durable, shared cache. The original turn stops burning its 10-minute budget while parsing runs separately; when the cached result is ready, a fresh agent turn resumes with a full new budget. Design doc + PR #124145 in progress (an earlier attempt, PR #118386, was closed unmerged); the underlying background-job infrastructure is already merged (PR #116590, #121463).

Separately, Joseph Tobin has already built the ability to split a large doc into smaller ones and parse them in parallel — "ready for launch but not enabled" yet.

Latest comment (just before this tracker was pulled): reassigned to Joseph Tobin, who is "rolling out the fix."

AIP-2397 Callable task isn't being triggered (price benchmark / spendhound) Medium
Assignee · Kaelyn Huang · Deployed to prod Aug 25, closed Aug 29
Fixed and shipped. Root cause was Anthropic rejecting edited reasoning blocks during a Chat→specialist handoff.
Details

Kaelyn Huang: "When Chat hands off to a specialist, the specialist replays Chat's message history, which contains routing tool calls it doesn't have, so we edit those calls out of the message before sending it to Anthropic. With thinking turned on that same message also carries signed reasoning blocks, and Anthropic rejects any message whose reasoning blocks were modified, so the request 400s and the specialist's turn dies before it ever replies."

Two PRs shipped the fix (#126712, #126577). Rollout: QA build v2026.08.21.qa on Aug 22 (prod ETA Aug 24) → deployed to Production as v2026.08.21.prod on Aug 25 → auto-closed Done, confirmed Aug 29.
